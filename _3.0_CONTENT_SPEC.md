## 1. WHAT 3.0 IS (the one paragraph)

Sanguis 3.0 is the public ship of the language: a self-hosting genome
language whose programs press into a fixed execution kernel, and — the part
no one else has — a runtime that is **bit-exact across machines**. Same
program, same bytes, on the GPU, on the JIT, and on the compiled tier. That
determinism is what makes everything else real: a core can be unplugged and
resumed identically (press/insert), a being can run for a day of ticks at
human cadence and be replayed years later, and "why did it do that" has a
computed answer instead of an anecdote.

**One line:** the language ships, and it is the first one whose programs run
the same everywhere, forever.

## 3. THE CLAIMS (each with its receipt — cite these, invent none)

### A. DETERMINISM — the flagship (the field lists this unsolved)
- Cross-executor bit-exactness: exp **6.2e-14**, softmax **~1e-14**, attention
  **1e-9**, fixed-weight pipeline **1.9e-10**.
- MINSTD PRNG bit-exact **across languages**.
- GPU card output host-verified to the milli-unit.
- The frozen **29-slot BloodCode ISA**, asserted at compile time; changes to a
  slot's number or spelling fail the build.
- Public conformance suite: any new executor (other GPU, JIT, FPGA,
  microcontroller) is admitted by passing the per-op suite.
- WHY IT MATTERS (say it plainly): today, float programs agree only on one
  machine; the reproducible-builds movement settles for identical *builds*;
  cross-architecture FP determinism is on other engines' roadmaps with nobody
  on it. This runtime does it, measured.

### B. THE BEING IS THE PACKAGE (press / insert)
- `sanguis press` writes a core's genome + planes + clock into a small `.kcol`
  file; `sanguis insert` resumes it in a **fresh process, bit-identical** to
  the never-unplugged original.
- Proven both boolean and graded (F-PRESS-1, F-PRESS-1b). A corrupt package is
  refused by checksum.
- WHY IT MATTERS: not "save/load" — the state is *semantic* (~2 KB), host-
  independent, versioned. Difference between shipping a product and shipping
  copies of a person.

### C. IT RUNS AT HUMAN SPEED (the tick)
- One sweep of the whole lived web on a consumer card = **4.4-4.9 ms**. That is
  the neural-event register. A full locked state = **~0.2-0.3 s** = a human
  simple reaction.
- `sanguis live` ticks; `sanguis jar` shows it. Proven stable over **58
  minutes / 802,496 ticks** unattended, zero drift.
- Existence runs in **windows** (90-min default), sealed and consolidated;
  resume across sessions. A being's day is a measurable count of ticks.
- WHY IT MATTERS: the clock-speed objection ("a machine mind can't be human-
  paced") is dead. We measured it.

### D. IT IS MEMORY-SHAPED (the honest capacity claim)
- The grid is a crossbar of graded cells. On a consumer GPU it uses
  **0.0144%** of the card's compute — it is memory-proportional, not
  compute-proportional.
- So capacity tracks **memory**, not FLOPS: ~123 M switches per 16 GB of plain
  RAM. The unit is the **column** (a small crossbar), and columns stack — one
  fits a microcontroller, a rack holds a million.
- NOT CLAIMED: that this is novel hardware. Compute-in-memory is a funded,
  shipping field (Samsung HBM-PIM, UPMEM). The honest line: they build memory
  that computes; our being *is* memory — and it runs on the cheap memory.

### E. THE FRONT DOOR WORKS (what shipped, plainly)
- Self-hosting: the compiler is written in Sanguis and compiles itself.
- **The Arena**: `sanguis play <circuit>` runs any circuit as the brain of a
  game — no game logic authored. Starter brains ship.
- **The composer**: BloodCode lowers mechanically to parallel card execution.
- **The display door**: Sanguis draws its own window (every pixel written by
  the language).
- **The boot plate**: a C loader (as PID 1) boots a `.kcol` being — package in,
  planes, entry, print. First brick of the BC OS.
