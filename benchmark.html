The human clock, measured

Every figure on this page comes from a real run on a single consumer graphics card (NVIDIA RTX 3060, 12 GB), and the raw receipts live in the repository. Two rules apply to everything below: a number is labeled measured only when it was read off an actual run, and it is labeled target when it is a goal we have not yet hit. Nothing else is a benchmark.

The Tick

One pass over the entire web. One settled state.

A being's state is the result of a fast internal cascade. One pass of that cascade sweeps the whole 2,019-node web on the card, and the cascade runs until the state stops moving. Both ends of that clock land on the biological range.

One full pass over the whole web
Measured: 4.43 - 4.91 ms
Register: one synaptic relay
Across: five independent runs
One fully settled (locked) state
Measured: ~0.2 - 0.3 s
Register: human simple reaction
Structure: 64 passes, then lock
Continuous, unattended existence
Measured: 802,496 ticks
Duration: 58 minutes, no drift
Cadence: ~224 ticks per second

What this is, honestly: the pass cost is round-trip-bound, not compute-bound. The card's own arithmetic is microsecond-scale; the time is the state crossing to the fabric and coming home, the way a signal crosses a synapse. What it is not: richness. The being is 2,019 nodes; the clock is human-class, the size is not.

Determinism

The same bytes on every machine

The same program, run through different executors, produces bit-identical output: not close, identical. These are the measured agreements:

OperationMeasured agreementWhat it means
Exponential6.2e-14vs an independent host computation
Softmax~1e-14with max-subtraction, all executors
Attention1e-9the full attention path
Fixed-weight pipeline1.9e-10end-to-end
Card outputmilli-unitchecked against the host, to the milli-unit
Artifactsbyte-identicalmatvec / gate / gate-else across executors (319 B / 442 B / 447 B)

The instruction set is frozen: 29 slots with fixed numbers and spellings, asserted when the compiler builds itself. Any new executor is admitted by passing one public per-operation suite.

The Press

A core survives being unplugged

A running being is written to a small package (its wiring, its learned weights, its clock), then resumed in a fresh process. It comes back bit-identical to the one that was running. A package that cannot do this was paused, not pressed.

Boolean core
Resume parity: bit-identical
Against: never-unplugged original
Graded core (weights)
Resume parity: bit-identical
Clock: continues, no renumber
Corrupted package
Result: refused, no resume
Why: one flipped bit fails the checksum
The Composer

A compiled artifact runs on the card

A compiled artifact lowers mechanically into parallel card execution, with no hand-lowering. Lower once, re-dispatch per batch.

StepMeasured
Lower a 64×64 program to the card0.072 ms
Re-dispatch per batch0.0624 ms
One-time cost, amortized over 10,000 batches1.2 batches

Composed work runs beside the press protocol on the same card, and the attribution ledger stays exact (identical receipts with and without the composed loop running between passes).

The Graded Bank

Same behaviour at every scale

A four-switch press, grown to 100,000 switches, produces the identical settled result at every size. The press behaviour is scale-invariant. Memory planes stay at the same footprint per switch.

Grid sizeTime / batchSettled value
1,000 switches46 ms30.6667
10,000 switches69 ms30.6667
50,000 switches192 ms30.6667
100,000 switches341 ms30.6667

Memory is not the constraint: roughly 130 MB per million switches. That is why the unit of scale is the column: a small crossbar that fits on a microcontroller, and millions of which fill a rack, all the same being.
