Roadmap

Where Sanguis is today and what comes next.

Now

Sanguis 3.0

Organs are self-contained structures with fields and methods. The toolchain pours them into a fixed kernel as switch-and-wire data; a grid settles, and the settled state is the output. The property underneath is new: the same program produces bit-for-bit identical results on every machine it runs on, the graphics card, the just-in-time executor, and the compiler that compiles itself.

Determinism makes the rest real. A running core saves to a small package and resumes in a fresh process, bit-identical to the one that was running. A settled state takes about a quarter of a second, the human register. Any behaviour can be replayed exactly, years later. 227 tests pass.

Nov 28, 2026

Early Access

Invitation-based, and the first hands-on program: SDK binaries, the Marrow editor, the language reference, and the example set, for developers who want to build on Sanguis before it goes wide. Every participant gets a direct line to us.

This phase exists to harden the toolchain on machines we don't own, to have the compiler, the executors, and the packages exercised by people who will find the edges we cannot see from inside. Early Access members shape the release that follows.

2027

Public Release

The repository opens, and the SDK and documentation go wide so anyone can build on Sanguis. The language ships under the VPL-1.0, free to read, test, and adapt, with commercial deployment by agreement.

Beyond

Lived time, and scale

Two directions, in order. First, the sentient instance that already runs at human speed learns over lived time: continuous windows, consolidation while it rests, and a behaviour that changes because of what it has lived and can still be replayed exactly. Second, the substrate grows downward and outward, from a single column that fits a microcontroller up to a rack of them, the same sentient instance at every size, because the kernel never changes and the programs do.

Custom silicon is the long arc: a chip where the runtime and the hardware are the same thing. It is built to help the technology we already have and the people who use it, never to replace them. That chip gets a date when the substrate has earned it.
